# Этап 04. Чекбоксы

**Статус:** ✅ готово

## Цель

Четыре чекбокса наборов символов: свой вид через `appearance: none`.

## Раскладка

Flex-колонка списка, Flex-строка «чекбокс + подпись».

## Токены

См. [tokens.md](tokens.md) — раздел «Чекбоксы».

## Субагенты

`scss-writer`

## Критерии готовности

- Совпадение с Figma на 375 / 768 / 1440.
- `npm run check` без ошибок.
- Клик по подписи переключает чекбокс, Space работает с клавиатуры.

## Факт реализации

Внесено ассистентом по просьбе пользователя, 2026-10-16. Файл: `src/scss/components/_settings.scss` — блок `__options` и новые `__option`, `__checkbox`, `__option-label`, два правила в `@include mixins.tablet`.

### Решения

- Чекбокс — сам `input` с `appearance: none`: Tab, Space, `:checked` и скринридер работают без доработок; без трюка с `label::before`.
- Галочка — `background-image: url('@/assets/images/icon-check.svg')` (14×12, без `background-size`): псевдоэлементы у `input` (replaced element) ненадёжны.
- Hover на всю строку: `.settings__option:hover &` внутри `&__checkbox` — все состояния чекбокса в одном блоке.
- `flex-shrink: 0` у квадрата; 20×20 и рамка 2px — в px. Фокус — единый стиль проекта (outline 2px green-200, offset 2px).
- Контраст: рамка grey-200 на grey-800 ≈ 12:1, галочка grey-850 на green-200 ≈ 15:1.

### Проверка

`npm run check` ✅, `icon-check-<hash>.svg` в `dist/assets/images/`. Playwright (Chromium), консоль пустая, SVG отдаётся с кодом 200:

| Ширина | Строка               | Между строками | Подпись                | Блок              |
| ------ | -------------------- | -------------- | ---------------------- | ----------------- |
| 375    | 311×20               | 16             | x 68 (20 + 16), 16/20  | слайдер → блок 32 |
| 768    | 476×24, квадрат y +2 | 16             | x 190 (20 + 24), 18/24 | 476×144           |

Клик по квадрату и по подписи переключает; Tab → outline, Space переключает; hover по подписи — рамка квадрата green-200.
