## Цель

Четыре чекбокса наборов символов: свой вид через `appearance: none`.

## Раскладка

Flex-колонка списка, Flex-строка «чекбокс + подпись».

## Токены

См. [tokens.md](tokens.md) — раздел «Чекбоксы».

## Субагенты

## Критерии готовности

- Совпадение с Figma на 375 / 768 / 1440.
- `npm run check` без ошибок.
- Клик по подписи переключает чекбокс, Space работает с клавиатуры.
