## Факт реализации

Внесено ассистентом по просьбе пользователя, 2026-10-16. Файлы: новые `src/scripts/password.ts`, `src/scripts/strength.ts`, `src/main.ts` переписан.

### Решения

- Чистая логика отдельно от DOM: `password.ts` (наборы `as const`, `getRandomIndex`, `shuffle`, `generatePassword`), `strength.ts` (`StrengthLevel` — union литералов, `STRENGTH_LABELS: Record<…>`, `getStrength`), `main.ts` — элементы, события.
- Случайность — только `crypto.getRandomValues`; индекс без modulo bias через rejection sampling на `Uint32Array`; перемешивание Фишера–Йетса.
- Если длина ≥ числа наборов — минимум по символу из каждого выбранного набора.
- DOM: generic-хелпер `getElement(id, HTMLInputElement)` с `instanceof`; чекбоксы — `form.elements.namedItem(name)`. Без `any`, `!`, `as`.
- Сила обновляется только по Generate; `renderStrength` не трогает live region, если уровень не изменился. Подсказка очищается строго `''`.
- Символы: `!@#$%^&*()-_=+[]{};:,.<>?/`.
