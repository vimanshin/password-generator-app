# Этап 00. Подготовка base

**Статус:** ✅ готово

## Цель

Фон страницы, минимальная высота экрана, базовые отступы страницы.

## Раскладка

Нет: только `html`/`body` в `base/_global.scss`.

## Токены

См. [tokens.md](tokens.md) — раздел «Страница».

## Субагенты

`scss-writer`

## Критерии готовности

- Совпадение с Figma на 375 / 768 / 1440.
- `npm run check` без ошибок.
- Градиент на весь экран без белых полос при прокрутке и overscroll.

## Факт реализации

Внесено ассистентом по просьбе пользователя, 2026-10-16. Файл: `src/scss/base/_global.scss`.

- `@use '../abstracts/mixins'` первой строкой.
- `:root`: `color-scheme: dark`.
- `body`: `min-height: 100svh`; padding 64 / 16 / 32 (mobile), сверху 133px (`8.3125rem`) от tablet; фон `--gradient-1` поверх `--color-grey-950`.
- Решения: градиент на `body` (background propagation на весь холст), `svh` вместо `vh`/`dvh`, отступы на `body`, а не на `main` — ширину колонки задаст класс блока на этапе 01.

Проверка: `npm run check` ✅. Playwright: 375 → padding `64px 16px 32px`; 768 и 1440 → `133px 16px 32px`; высота `body` равна экрану, лишней прокрутки нет; консоль пустая.
