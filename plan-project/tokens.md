# Токены Figma

Глобальные токены объявлены в `src/scss/base/_global.scss` (цвета, `--gradient-1`, `--font-mono`, `--spacing-*`) и `src/scss/abstracts/_mixins.scss` (`text-preset-1…4`). Здесь — как они применяются.

Пресеты: 1 = 32/42 · 2 = 24/32 · 3 = 18/24 · 4 = 16/20. Шрифт везде JetBrains Mono Bold. `border-radius` нигде нет (0), теней нет.

## Неизвестно

- Focus-состояния в макете не нарисованы → делаем `:focus-visible` с outline green-200.
- `COPIED` на mobile снят по метаданным (ширина 58 на 6 символов = 16px, gap по позициям 8) — по стилю текста не подтверждено.
