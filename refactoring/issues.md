# Вне scope рефакторинга

- **px вместо rem** у слайдера, чекбокса и полосок силы (`_settings.scss`, `_strength.scss`): не масштабируются при увеличении базового шрифта в браузере. Перевод в rem меняет рендер — отдельная a11y-задача.
- **`src/assets/fonts/README.txt`** описывает variable-файлы, которых в проекте нет, а лицензия `OFL.txt` рядом со шрифтом отсутствует. OFL требует прикладывать лицензию при распространении шрифта — решить отдельно (добавить OFL.txt, README заменить/удалить).
- **Предупреждение Chrome о `preload` шрифта** («preloaded … but not used within a few seconds») появляется при повторной загрузке страницы, когда шрифт уже в кеше. Воспроизводится и на baseline-сборке `724c623` — существовало до рефакторинга. На первой загрузке предупреждения нет. Разобраться отдельно, если мешает.
