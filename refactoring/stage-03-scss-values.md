## Контроль риска

- Sass вычисляет переменные при сборке: `28px`, `8px`, `-10px` в CSS остаются прежними
- F7: цепочка предков каждого элемента до `:root` проверена — другого `color` нет ни на одном брейкпоинте и в hover

## До → после

- `width: 28px` / `height: 8px` → `$slider-thumb-size` / `$slider-track-height`
- `margin-top: -10px` → `math.div($slider-track-height - $slider-thumb-size, 2)`
- `color: var(--color-grey-200)` ×4 → удалено, цвет наследуется от `:root`
