# Этап 2. Миксины focus-ring и transition

**Статус:** ⏳ · **Findings:** F4, F5 · **Риск:** 🟡 · **Writer:** scss-writer

## Контроль риска

- Specificity всех селекторов не меняется — меняется только источник деклараций
- `@media (prefers-reduced-motion)` может сместиться в выводе: проверить, что ни одно правило между старым и новым местом не задаёт `transition` для того же элемента
- Значения (2px, green-200, 0.2s ease) не меняются

## Критерии готовности

- [ ] CSS отличается от baseline только порядком правил
- [ ] Focus-кольца и hover-переходы визуально прежние
